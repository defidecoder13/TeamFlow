# Technology Stack

## Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- TanStack Query for server state
- Zustand for focused client state
- Dexie for IndexedDB
- PWA/service worker

## Backend

- Node.js
- Express
- TypeScript
- Socket.IO
- Zod for request/event validation

## Data

- PostgreSQL
- Prisma ORM
- Neon for hosted PostgreSQL
- pgvector for embeddings

## Infrastructure

- Redis
- BullMQ
- Cloudflare R2 or S3
- Docker
- CI/CD

## AI

- OpenAI API
- Embeddings
- Retrieval augmented generation

## Design principle

Use the minimum number of infrastructure components needed for the current stage. Every additional dependency must have a concrete reason.
