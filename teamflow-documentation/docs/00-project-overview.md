# Project Overview

## Product

TeamFlow is a multi-tenant team collaboration application inspired by Slack, with a deliberate focus on real-time communication, offline reliability, and permission-aware AI assistance.

## Primary users

- Small development teams
- Startups
- Student/project teams
- Remote teams

## Core value

Teams can communicate in persistent workspaces while retaining reliable access during intermittent connectivity and using AI to find and summarize organizational knowledge.

## Success criteria

- Messages appear in real time.
- Users can work across multiple workspaces.
- Permissions are enforced consistently.
- Previously loaded conversations remain readable offline.
- Offline messages eventually synchronize safely.
- AI answers are grounded in accessible workspace conversations.
- The system can scale horizontally at the realtime layer.
- Critical flows are covered by automated tests.

## Scope

### MVP

Authentication, workspaces, members, channels, DMs, messaging, threads, reactions, presence, notifications, file attachments, search, basic offline support.

### Advanced

AI/RAG, advanced search, scheduled messages, polls, bookmarks, audit logs, background processing, observability, horizontal realtime scaling.
